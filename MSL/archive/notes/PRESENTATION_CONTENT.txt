SLIDE 6: DATA PREPROCESSING PIPELINE
================================================================================

CRITERIA 2: DATASET PREPARATION & PREPROCESSING

Our Preprocessing Steps:

Step 1: Feature Loading
- Input: Pre-extracted Video Swin features (H5 format)
- Feature dimension: 1024-D
- Temporal snippets: Variable length per video
- Implementation: H5 dataset loader

Step 2: Video Name Mapping
- Challenge: List file names ≠ H5 key names
- Example: "Abuse/Abuse001_x264.mp4" → "Abuse001"
- Solution: Smart fuzzy matching
  • Remove path prefix
  • Remove "_x264" suffix
  • Extract video number
  • Match to H5 keys
- Success rate: 100% (all 1,501 train + 290 test mapped)

Step 3: Label Extraction
- Method: Parse video filename
- Rule: Videos with "Normal" in name → label = 0
- Rule: All other videos → label = 1 (anomaly)
- Validation: Checked against ground truth file

Step 4: Sequence Handling
- Max length: 100 temporal snippets
- Padding: Zero-padding for shorter videos
- Truncation: Cut longer videos to max_length
- Masking: Boolean mask for valid positions

Step 5: Batch Collation
- Collate variable-length videos into batches
- Stack features: (batch_size, max_length, feature_dim)
- Stack labels: (batch_size,)
- Stack masks: (batch_size, max_length)

Implementation Files:
- src/datasets/ucf_crime_h5.py
- src/datasets/collate.py
