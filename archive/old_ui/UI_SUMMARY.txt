🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"Can't upload videos"
  → Check file size and format
  → Ensure uploads/ directory exists
  → Verify Flask is running

"UI not loading"
  → Clear browser cache
  → Check Flask server status
  → Try different browser

"Analysis stuck"
  → Check model checkpoint exists
  → Verify GPU/CUDA availability
  → Review Flask console logs

"Port already in use"
  → Use: python run_web_ui.py --port 8080
