═══════════════════════════════════════════════════════════════════════
  🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

  Server won't start?
    → Try different port: python run_web_ui.py --port 8080

  Dependencies missing?
    → Install: pip install -r requirements_web.txt

  Can't upload videos?
    → Check file size (<500MB) and format (MP4/AVI/MOV/MKV)

  UI not loading?
    → Clear browser cache, try incognito mode

  Need help?
    → Check documentation in WEB_UI_README.md
